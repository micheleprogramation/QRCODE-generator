**QR Code Generator em Python**



A simple Project in Python to generate QR Codes in a simple way and fast using qrcode library.



**Functionalities**



Generate QR Code as of any text or URL

Save the image in .png format

Easy to modify and reuse



**Technologies used**



Python 3

Biblioteca qrcode



**How to use**



1. generate\_qr\_code('https://www.python.org', '1.png')
2. python qr\_code\_generator.py



The qrcode will be saved as 1.png
